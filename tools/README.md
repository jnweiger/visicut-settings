vcsetman
========

Visicut can save settings for different profiles (cut, mark, engrave, ...), different materials (plywood, acrylics, paper, ....) and thicknesses.
It uses several internal java datastructures - when saving, these data structures are serialized into xml files.
Settings can also be downloaded from a registered GitHub Repository per Lab.

This approach comes with a few shortcomings
-------------------------------------------

* The settings files cannot be edited easily. There are many interdependencies among the files. Filenames and path components bear meaning. 
* For different lasercutter devices, the XML schema differs to accomodate for the specific features per device. New devices appear as new XML classes.
* Downloading published settings from a Lab overwrite all user generated settings (settings from other Labs) without warning.
* Adding a new setting manually for one laser (and material, and thickness), automatically makes the setting appear for all other lasercutter devices. The missing values are silently filled in with 0 or other defaults (typical "20%").

Vcsetman.py addresses these issues through the following features
-----------------------------------------------------------------

* Import from / export to a wiki table markdown format. This is our prefered form of edit and exchange at e.g. https://wiki.fablab-nuernberg.de/w/Nova_35
* Check for missing values in XML data. Offer automatic interpolation / exttapolation of missing data controlled by laserprofiles/generator.json
* Support a comments column in the wiki tables. (e.g. stating the source of a setting, autogenerated, uman user, wiki page, ...) This is saved as laserprofiles/annotations.json within the XML data tree.
* Support merging settings from multiple sources. E.g. local data, remote github settings, wiki page.

Note
----
laserprofiles/generator.json is rather compact. Its compactness can be further proved by implementing the example line marked as "FUTURE". This may become a nice interchange format across similar tools some time.
